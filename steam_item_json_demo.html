Ver JSON da Steam no Chrome

Um item só (preços resumidos) — endpoint oficial do Community Market, resposta JSON:

/market/priceoverview/ com appid, currency e market_hash_name.

  • currency=7 → real (BRL)
  • O nome do item deve estar URL-encoded (espaços → %20, |, ★, etc.)
